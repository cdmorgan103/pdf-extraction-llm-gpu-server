All extracted values were identical to the development runs except one document:
INV-0008 (scanned). Its first answer failed an arithmetic check (line 3 amount), and
the retry corrected it this time (3,322.00 = 20 x 166.10), where in development the
retry had not improved it. The model is deterministic for a single request
(temperature 0), but a retry conversation can come out slightly differently on a GPU.
That is why golden_check.py allows a 3-point tolerance before failing a set.

Expected on the GPU server: the same PASS results. A different GPU model or driver can
shift individual retry outcomes in the same way, so small differences within the
tolerance are normal; a FAIL is not.
